# 🛡️ Women Safety Analytics Prototype

A Smart India Hackathon 2024 prototype that uses real-time computer vision to:
- Detect gender and age of individuals
- Count number of males and females around
- Detect "HELP" hand gesture to signal distress

Built with:
- OpenCV
- MediaPipe
- DNN Age-Gender Models

## 🔍 Features
- Real-time face detection
- Age and gender prediction
- HELP gesture detection (raise all fingers gesture)
- Count and display of males and females in frame
